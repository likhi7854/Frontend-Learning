JavaScript (JS) Overview

Core Concepts

JavaScript is a high-level, dynamic programming language that enables interactive web features, client-side logic, and asynchronous data operations.

Key Features

  • DOM Manipulation: Dynamically access and modify HTML elements and CSS styles.
  • Event Handling: Listens and responds to user actions like clicks, keyboard inputs, and scrolling.
  • Asynchronous Programming: Uses Promises and async/await to fetch remote data without blocking the browser.

Basic Script Example

// Function declaration
function greetUser(name) {
  return `Hello, ${name}!`;
}

// Event Listener Example
const button = document.querySelector('#myBtn');
button.addEventListener('click', () => {
  console.log(greetUser('Developer'));
});
