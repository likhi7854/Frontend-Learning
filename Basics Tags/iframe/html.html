HTML (HyperText Markup Language)

Core Concepts

HTML is the standard markup language used to create and design the layout of web pages. It structures content using elements represented by tags.

Key Components

  • Elements & Tags: Enclosed in angle brackets, such as <h1>, <p>, and <div>.
  • Attributes: Provide additional info about elements, like href for links or src for images.
  • Semantic Structure: Uses meaningful tags like <header>, <article>, and <footer> for better accessibility and SEO.

Standard Document Structure

<!DOCTYPE html>
<html lang="en">
<head>
  <title>Page Title</title>
</head>
<body>
  <h1>Main Heading</h1>
  <p>Paragraph content goes here.</p>
</body>
</html>
